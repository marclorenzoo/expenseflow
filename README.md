# ExpenseFlow

Modern collaborative expense management SaaS built with Angular 20 + NestJS.

## Stack

- **Frontend**: Angular 20, TypeScript, TailwindCSS, Signals, TanStack Query
- **Backend**: NestJS, Prisma, PostgreSQL, JWT
- **Deploy**: Vercel + Railway + Neon PostgreSQL

## Structure

\```
expenseflow/
├── frontend/   # Angular 20
└── backend/    # NestJS
\```
